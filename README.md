# Online Event Ticketing System

## Overview  
This is a full-stack web application for an **Online Event Ticketing System** that allows users to browse, search, and book tickets for various events such as concerts, sports games, and theater shows.

## Project Objectives  
- Implement **CRUD operations** for managing users, events, and bookings.  
- Develop a **frontend and backend** for a functional and interactive system.  
- Apply **project structuring & component-based design** best practices.  

## User Roles  
1. **Standard User**: Browse events, book tickets, and view booking history.  
2. **Event Organizer**: Create, update, and delete events.  
3. **System Admin**: Manage users and events with full system control.  

## Key Features  
- **Homepage**: Displays upcoming events with details (name, date, location, price).  
- **Event Details Page**: Provides booking options for users.  
- **Ticket Booking System**: Users can select tickets, check availability, and proceed to checkout.  
- **Search & Filter**: Find events by name, category, date, or location.  
- **User Dashboard**: Shows booked tickets and event history.  
- **Admin Panel**: Enables event management for organizers.  
- **Database Integration**: Stores user data, events, and bookings using **MongoDB**.
